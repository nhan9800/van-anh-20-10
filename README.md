# Gửi Vân Anh · 20/10/2026

Website kỷ niệm Ngày Phụ nữ Việt Nam 20/10 dành riêng cho Vân Anh.

## Website

**[Mở website trên GitHub Pages](https://nhan9800.github.io/van-anh-20-10/)**

## Chạy local

```bash
npm install
npm run dev
```

Mỗi lần push lên nhánh `main`, GitHub Actions sẽ tự build và cập nhật GitHub Pages.

Thiệp dùng bản preview được Spotify cung cấp cho ca khúc “để dành cho em”. Người xem có thể phát/tạm dừng trong khung nhạc hoặc mở bản đầy đủ qua các liên kết chính thức. Trình duyệt có thể chặn tự phát âm thanh; khi đó hãy nhấn Play trong khung Spotify.

Hoa rơi bắt đầu khi mở thiệp. Nếu thiết bị bật chế độ giảm chuyển động, trang hiển thị hoa tĩnh và có nút “Bật hoa rơi” để người xem tự chọn hiệu ứng.
